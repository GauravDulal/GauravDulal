## About Me

- I build full-stack products with a strong focus on booking workflows, admin dashboards, and production-ready APIs.
- Recent work shows a lot of hands-on effort in Next.js + TypeScript frontends and Python/FastAPI backends.
- I enjoy shipping practical automation tools, from social-message appointment systems to notification bots and CV-powered apps.
- I like improving reliability and security through iterative commits (auth hardening, payment verification, and bug-fix cycles).
- Outside pure coding, I enjoy shaping ideas into tools that solve everyday problems.

## Currently Exploring
